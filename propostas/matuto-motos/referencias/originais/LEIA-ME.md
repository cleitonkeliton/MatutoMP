# Pasta de entrada dos prints

Se as fotos forem enviadas pelo GitHub em vez do chat, solte aqui os prints do Instagram
(JPG, PNG ou WEBP, com qualquer nome).

No GitHub: abra esta pasta na branch `claude/nice-ptolemy-5vfv5q` → **Add file** →
**Upload files** → arraste as imagens → **Commit changes** direto nessa branch.

Ao processar, cada imagem é registrada em `../INVENTARIO.md` e movida para `../fotos/`
com o id correspondente (P1-01, P1-02...). Esta pasta fica vazia de novo.
