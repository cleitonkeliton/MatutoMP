# Inventário de referências — Matuto Motos

Prints do Instagram @matutomotospecas enviados pelo cliente.

- Arquivo de cada imagem: `referencias/fotos/<id>.png` (print original, renomeado pelo id).
- Visão geral com todas as miniaturas numeradas: `referencias/indice-fotos.jpg`.
- Os recortes usados no site (só a foto ou a arte, sem a interface do Instagram) serão gerados
  na fase de construção, a partir destes originais.
- **id**: `P<parte>-<nº>`. Como todas as fotos chegaram juntas pelo repositório, há uma parte só
  (P1), numerada pela ordem dos prints (horário da captura).
- **Tipos**: produto · promoção · logo/identidade · loja · dono/equipe · depoimento ·
  informação (endereço, horário, pagamento).
